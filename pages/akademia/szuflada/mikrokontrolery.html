1. ESP32-C3: pierwsze uruchomienie

Podłącz ESP32 do USB. W Arduino IDE wybierz płytkę. Wgraj program.

ESP32 00 — tylko się zaświeci

void setup() {
  pinMode(8, OUTPUT);
}
void loop() {
  digitalWrite(8, HIGH);
  delay(1000);
  digitalWrite(8, LOW);
  delay(1000);
}

Zmień pin 8 na inny. Co się stanie?

Uwaga: nie każdy pin ESP32-C3 nadaje się do LED. Sprawdź w dokumentacji.

0–A–Anna 1–B–Barbara 2–C–Celina 3–D–Dorota 4–E–Eliza
