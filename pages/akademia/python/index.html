  1. IDE. W przypadku języka Python, IDE łączy w jednej aplikacji wszystkie narzędzia potrzebne do pisania, testowania i uruchamiania kodu.

    3x🏆 Najpopularniejsze IDE dla Pythona
    W świecie Pythona najczęściej korzysta się z kilku sprawdzonych narzędzi:
    1. PyCharm (od JetBrains) Wersja Community jest całkowicie darmowa.
    2. Visual Studio Code (VS Code) (od Microsoftu)
    3. Thonny środowisko programistyczne stworzone specjalnie dla osób rozpoczynających naukę programowania w języku Python .
