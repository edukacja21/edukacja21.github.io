🧠 Memory 4×4 — kamień milowy

Plansza ASCII, pętle, listy i zagadki z błędami

1. O czym jest ten materiał

To kamień milowy, nie pierwsze ćwiczenie. Zakładamy, że znasz już while, listy i if. Tutaj łączymy to w większy program: planszę 4×4, rysowanie ASCII, czyszczenie ekranu i sprawdzanie par.

Uwaga: ten kod działa dla poprawnych danych. Twoje zadanie to znaleźć miejsca, w których się wywala, i zastanowić się, jak je zabezpieczyć. To część nauki — nie błąd materiału.

2. Kod do skopiowania

Uruchom w Thonny. Graj tak długo, aż znajdziesz wszystkie 8 par. Potem wróć do sekcji z zagadkami.

import random
import os
import time

# Przygotowujemy 8 par emoji lub liter
karty = ["😀","🐱","🌟","🍎","🎵","⚽","🚗","🌈"] * 2
random.shuffle(karty)

# Na początku wszystkie pola zakryte
odkryte = []
for i in range(16):
    odkryte.append(False)

pary = 0
proby = 0

while pary < 8:
    os.system("cls" if os.name == "nt" else "clear")

    print("   1     2     3     4")
    print()

    # RYSOWANIE PLANSZY ASCII
    for rzad in range(4):
        linia1 = chr(65+rzad) + " "
        linia2 = "  "
        linia3 = "  "

        for kol in range(4):
            i = rzad*4 + kol
            if odkryte[i]:
                linia1 += "+-+  "
                linia2 += "|" + karty[i] + "|  "
                linia3 += "+-+  "
            else:
                linia1 += "###  "
                linia2 += "# #  "
                linia3 += "###  "

        print(linia1)
        print(linia2)
        print(linia3)
        print()

    print("Znalezione pary:", pary, "/ 8")
    print("Próby:", proby)
    print()

    # --- WYBÓR 1. ---
    w1 = input("Pierwsze pole (np. A1): ").strip()
    r1 = ord(w1[0].upper()) - 65
    k1 = int(w1[1]) - 1
    i1 = r1*4 + k1

    while odkryte[i1]:
        print("To pole jest już odkryte!")
        w1 = input("Pierwsze pole (np. A1): ").strip()
        r1 = ord(w1[0].upper()) - 65
        k1 = int(w1[1]) - 1
        i1 = r1*4 + k1

    odkryte[i1] = True

    # Rysujemy ponownie planszę
    os.system("cls" if os.name == "nt" else "clear")

    print("   1     2     3     4\n")
    for rzad in range(4):
        l1 = chr(65+rzad) + " "
        l2 = "  "
        l3 = "  "
        for kol in range(4):
            i = rzad*4 + kol
            if odkryte[i]:
                l1 += "+-+  "
                l2 += "|" + karty[i] + "|  "
                l3 += "+-+  "
            else:
                l1 += "###  "
                l2 += "# #  "
                l3 += "###  "
        print(l1)
        print(l2)
        print(l3)
        print()

    # --- WYBÓR 2. ---
    w2 = input("Drugie pole (np. B3): ").strip()
    r2 = ord(w2[0].upper()) - 65
    k2 = int(w2[1]) - 1
    i2 = r2*4 + k2

    while i2 == i1 or odkryte[i2]:
        print("Nieprawidłowe pole, spróbuj jeszcze raz.")
        w2 = input("Drugie pole (np. B3): ").strip()
        r2 = ord(w2[0].upper()) - 65
        k2 = int(w2[1]) - 1
        i2 = r2*4 + k2

    odkryte[i2] = True

    # Rysujemy z drugim wyborem
    os.system("cls" if os.name == "nt" else "clear")

    print("   1     2     3     4\n")
    for rzad in range(4):
        l1 = chr(65+rzad) + " "
        l2 = "  "
        l3 = "  "
        for kol in range(4):
            i = rzad*4 + kol
            if odkryte[i]:
                l1 += "+-+  "
                l2 += "|" + karty[i] + "|  "
                l3 += "+-+  "
            else:
                l1 += "###  "
                l2 += "# #  "
                l3 += "###  "
        print(l1)
        print(l2)
        print(l3)
        print()

    proby += 1

    # SPRAWDZAMY PARĘ
    if karty[i1] == karty[i2]:
        print("BRAWO! To para!")
        pary += 1
    else:
        print("To nie para :(")
        time.sleep(1)
        odkryte[i1] = False
        odkryte[i2] = False

    time.sleep(0.5)

os.system("cls" if os.name == "nt" else "clear")
print("GRATULACJE! Znalazłeś wszystkie pary w", proby, "próbach!")

3. Zagadki — co się stanie, gdy…

Uruchom program i spróbuj odpowiedzieć najpierw na kartce, potem sprawdź w Thonny. To nie jest test — to ćwiczenie z czytania kodu.

Zagadka 1 — A zamiast A1 Co się stanie, gdy wpiszesz A (bez cyfry) jako pierwsze pole? Dlaczego? W którym miejscu kodu program się zatrzyma?
Zagadka 2 — A5 Co się stanie, gdy wpiszesz A5? Czy program się wywali, czy „cicho” zaznaczy inne pole? Policz: r1 = ord('A') - 65 = 0, k1 = 5 - 1 = 4, czyli i1 = 0*4 + 4 = 4. Które to pole na planszy?
Zagadka 3 — zakres A1–D4 Jak sprawdzić, czy pole mieści się w zakresie A1–D4? Zapisz warunek, który to sprawdza — zanim program spróbuje użyć w1[1] albo odkryte[i1]. Podpowiedź: potrzebne są dwa sprawdzenia — jedno dla litery, drugie dla cyfry.
Zagadka 4 — powtórzone rysowanie W kodzie plansza rysowana jest trzy razy (przed wyborem 1, po wyborze 1, po wyborze 2). Za każdym razem ten sam blok for rzad in range(4). Spróbuj wydzielić to do funkcji rysuj_plansze(odkryte, karty). Co trzeba jej przekazać? Co zwraca?

Wskazówka do zagadki 3: zamiast int(w1[1]) możesz najpierw sprawdzić, czy w1 ma dokładnie 2 znaki, czy pierwszy znak to litera A–D, a drugi to cyfra 1–4. Dopiero potem liczyć i1.

4. Zadania — co zrobić dalej?

1. Zabezpiecz wejście Dodaj sprawdzanie, czy pole mieści się w zakresie A1–D4. Program nie może się wywalić — ma poprosić o ponowne wpisanie.
2. Wydziel funkcję Przenieś rysowanie planszy do funkcji rysuj_plansze(odkryte, karty) i wywołuj ją w trzech miejscach zamiast kopiować kod.
3. Licznik prób Czy licznik proby rośnie w dobrym miejscu? Sprawdź, czy nie liczy podwójnie, gdy gracz trafi parę.
4. Wersja na 4 pary Zmień planszę na 2×4 (8 kart, 4 pary) i sprawdź, co trzeba zmienić w kodzie: rozmiar listy, pętlę rysowania, warunek końca.
