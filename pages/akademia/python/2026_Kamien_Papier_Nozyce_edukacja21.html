Mini-projekt Python — instrukcje warunkowe w praktyce

1. O czym jest to zadanie

Krótka, zabawna gra do nauki instrukcji warunkowych (if / elif / else). Ta wersja jest zapisana w najprostszej, najczytelniejszej formie — idealna na pierwszy kontakt z if.

Uwaga: Nie edytuj długich linijek na telefonie — ustaw urządzenie w poziomie, albo lepiej użyj laptopa. „Take it easy — no stress.” 😉

2. Obrazki (dane do skopiowania)

Skopiuj każdy obrazek osobno. Zwróć uwagę na spacje — to one tworzą rysunek.

kamien

kamien = '''
    _______
---'   ____)
      (_____)
      (_____)
      (____)
---.__(___)
'''

papier

papier = '''
    _______
---'   ____)____
          ______)
          _______)
         _______)
---.__________)
'''

nozyce

nozyce = '''
    _______
---'   ____)____
          ______)
       __________)
      (____)
---.__(___)
'''

3. Kod gry

Obrazki z poprzedniej sekcji są już zdefiniowane — tutaj zaczynamy od listy i logiki gry.

import random

obrazki = [kamien, papier, nozyce]

print("Witaj w grze!")
user_input = int(input("Co wybierasz? Wpisz: 0 jeśli Kamień, 1 jeśli Papier, 2 jeśli Nożyce\n"))

# Sprawdzamy błędny wybór
if user_input < 0 or user_input > 2:
    print("Wprowadzono błędną liczbę. Koniec gry.")

else:
    print("Twój wybór:")
    print(obrazki[user_input])

    computer = random.randint(0, 2)
    print("Komputer wybrał:")
    print(obrazki[computer])

    # Proste, czytelne ify — najlepsze na start
    if user_input == computer:
        print("Remis!")

    elif user_input == 0 and computer == 2:
        print("Wygrywasz! (Kamień miażdży Nożyce)")

    elif user_input == 1 and computer == 0:
        print("Wygrywasz! (Papier owija Kamień)")

    elif user_input == 2 and computer == 1:
        print("Wygrywasz! (Nożyce tną Papier)")

    else:
        print("Przegrywasz :(")

4. Wytłumaczenie krok po kroku

  • Linie 1–3: importujemy random do losowania wyboru komputera.
  • Obrazki: ASCII-art dla Kamienia / Papieru / Nożyc — fajna nagroda wizualna.
  • Sprawdzenie poprawności: jeśli uczeń wpisze 5, program kończy się ładnie.
  • Instrukcje warunkowe: każdy przypadek wygranej wypisany osobno — proste do zrozumienia i poprawiania.

5. Zadania — co zrobić dalej?

1. Komentarze Dodaj komentarze do każdej instrukcji if, tłumacząc po polsku, dlaczego to wygrywa.
2. Licznik rund Po każdej grze pytaj „Jeszcze raz? (t/n)” i licz, ile razy wygrał gracz, a ile komputer.
3. Zmiana grafiki Zastąp ASCII krótkim emoji (🪨 📄 ✂️) i sprawdź, czy działa tak samo.
4. Wersja punktowa Daj 1 punkt za wygraną, −1 za przegraną, sumę pokaż na końcu.

6. Bonus (dla chętnych)

Uprość kod, używając słownika wygrywa_z — to lekcja dla zaawansowanych:

wygrywa_z = {0: 2, 1: 0, 2: 1}
if wygrywa_z[user_input] == computer:
    print("Wygrywasz!")
